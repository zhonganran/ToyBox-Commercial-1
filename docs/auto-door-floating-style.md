# 自动滑门悬浮窗样式备忘

这个样式来自已删除的自动电滑门悬浮窗，后续如果要复用，可以按下面的视觉结构重建。

- 整体：透明悬浮卡片，不使用整块实色背景，内容横向排列。
- 布局：左侧车辆图卡 + 间距 + 左侧滑门卡片 + 间距 + 右侧滑门卡片。
- 左侧车辆图卡：玻璃拟态圆角面板，白色半透明描边/底色，内部放完整车辆图，图片上覆盖轻微暗色蒙层。
- 左/右门卡片：独立圆角玻璃卡片，左侧使用浅青蓝强调色，右侧使用暖黄色强调色。
- 文字层级：卡片标题为门名，状态文案显示当前状态，主操作文案为打开/关闭/暂停。
- 图标：门卡片内有线框车门和方向箭头，线条白色，箭头使用对应强调色。
- 交互：卡片点击执行主操作，长按切换固定/可拖动；支持透明度、大小和位置调节。
- 默认参数：透明度 94%，大小 100%，透明度范围 35%-100%，大小范围 75%-135%。
