# 超级玩具箱微信小程序

原生微信小程序工程，直接使用微信开发者工具打开 `miniapp` 目录。

## 开发预览

项目使用 `touristappid` 时自动启用演示数据，便于直接预览全部页面与状态。填写正式 AppID 后会自动切换为真实服务器接口。

正式接入时：

1. 在 `project.config.json` 中填写正式小程序 AppID。
2. 在微信公众平台配置 `https://api.689588.xyz` 为 request 合法域名。
3. 将 `https://cdn.689588.xyz` 配置为 downloadFile 合法域名。
4. 云端配置 `WJX_MINIAPP_APP_ID`、`WJX_MINIAPP_APP_SECRET` 并重启后台。

## 页面

- 首页：车辆在线状态、能源、续航、环境、行程和快捷入口。
- 行程：行程轨迹、月度汇总、历史行程与充电记录。
- 工具：音效库、自动化、车机诊断、使用说明与版本更新。
- 我的：车辆绑定、授权状态、日志记录和客户服务。

## 数据原则

- 正式模式只显示车机和服务器实际同步的数据，缺失字段显示 `--`。
- 车辆离线时保留最后同步值，并明确显示离线与同步时间。
- 日志上传区分“请求已发送”“车机已接收”和“日志已上传”。
- 一次性车辆绑定码默认十分钟有效，使用后立即失效。
