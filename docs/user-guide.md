# 超级玩具箱使用说明

本手册适用于当前稳定版。不同车型、年份和 DiLink 版本开放的车辆数据与仪表能力可能不同，请以实车读取和预览结果为准。涉及画面预览、车辆控制、方向盘按键学习的操作，请在车辆静止并确保周围安全时进行。

## 1. 首次安装与权限

1. 安装后首次打开应用，阅读安全声明并选择同意。
2. 按首次启动顺序允许文件读取与写入、位置、后台位置、麦克风、蓝牙和通知权限，并确认定位与蓝牙系统开关已经打开。
3. 按引导开启悬浮窗、通知读取和两项无障碍服务；返回应用后会自动进入下一项。
4. 按自启动引导为超级玩具箱开启自启动、后台运行或电池优化白名单。没有这些权限时，车机重启后自动联动、行程记录和后台组件可能无法恢复。
5. 如果系统弹出 ADB 连接确认，勾选“始终允许这台设备”后确认。车辆数据、方向盘按键、仪表投射和部分车辆控制依赖此连接。
6. 在“设置 → 数据与更新 → 权限与运行环境”查看授权状态；“自动修复”会重新执行使用情况访问、通知读取、悬浮窗、无障碍和 Helper 等内部授权。
7. 应用内更新安装时，系统会按需打开“允许安装未知应用”；允许后返回应用会重新校验 APK 并自动继续安装。

拒绝或后来撤销运行时权限时，应用会在下次启动重新检查；功能页面仍保留按需授权入口。

## 2. 试用、激活与车辆绑定

1. 打开“设置 → 授权激活”，等待应用读取当前车辆的 17 位 VIN。
2. 新车辆首次成功连接授权服务器后进入试用，设置页会显示“试用”“已激活”或“已到期”。
3. 获得激活码后，将其粘贴到输入框并点击“立即激活”。激活码会与当前 VIN 绑定，不能直接换车使用。
4. “服务与授权”中可查看客服和售后信息，也可复制 VIN 用于授权核对。
5. 重装、清除应用数据或恢复车机后，只要应用仍能读取原车辆的真实 VIN，联网查询时会直接恢复服务器上已绑定的永久授权。
6. 联网查询授权时，应用会同时上报车机读取到的车辆名称、VIN 年款、车型变体、车系、动力类型和控制器版本，供售后后台识别车型；服务器不会通过 VIN 猜测销售款型。

## 3. 首页车辆数据

首页用于快速查看车辆当前状态：

- 车辆卡片：SOC、车速、实时功率和数据连接状态。
- 续航与能源：纯电续航、燃油续航、总续航、油量、实时功率和总里程。
- 动力系统：发动机、前电机和后电机状态；车型没有对应部件或未开放信号时会显示空值。
- 车辆图片：点击车辆图片区可从相册选择图片，长按可删除自定义图片并恢复默认图。
- 数据刷新：车辆上电后按读取周期更新；熄火后可能保留最后一次有效值。

纯电续航和燃油续航直接读取原车仪表/BMS 数据；总续航相加当前车型实际提供的续航项，因此纯电车型会直接显示纯电续航。全程不使用本地能耗估算。电池、油箱和价格参数仅用于剩余能源、费用与充电统计。

## 4. 车辆详细状态

点击首页中的分析卡片可进入详细页面：

- 本次能量回收：查看当前行程及累计的回收电量、发动机发电量。
- 车机系统：查看 CPU、核心占用、内存、存储、GPU、温度和进程状态。
- 电池健康：查看 SoH、总电压、单体最高/最低电压、压差、电池温度和 12V 蓄电池。
- 车身环境：查看车门、车窗、空调、轮胎、灯光、安全带和驾驶辅助状态。
- 本地分析：根据已记录的行程计算能耗、费用和变化趋势。

页面显示“--”或“暂不可读”，通常表示当前车型没有该传感器、车辆已熄火，或车机没有开放该数据。

## 5. 行程与 GPS 轨迹

1. 车辆上电并开始行驶后，应用会根据电源、档位、车速和里程变化自动建立行程，停车熄火后自动结束。
2. 从首页进入“行程与轨迹”，可按日、周、月、年或全部时间筛选。
3. 每条行程包含起止时间、时长、里程、用电、用油、电费和油费。
4. 需要地图路线时，在“设置 → 数据与更新”开启“记录行程 GPS 轨迹”，并允许位置权限。
5. 在地图上选择一条或多条行程，点击“适配视图”可让全部所选路线进入可见区域。

关闭 GPS 轨迹不会影响里程和能耗记录，也不会删除已经保存的轨迹。

## 6. 充电与充电记录

1. 插枪并开始充电后，充电页面会识别慢充或快充，并显示功率、电流、电压、本次充入电量和停止 SOC。
2. 充电结束后自动生成历史记录，可按时间以及慢充/快充筛选。
3. 点击月份和日期可展开详细记录；长按单条记录可编辑或删除。
4. 自动记录缺失时，点击“新增充电”手工填写时间、SOC、类型、电量和费用。
5. 统计区可查看次数、总电量、总费用、平均单价，以及 SoH、电芯压差和温度趋势。

自动记录依赖充电枪、BMS 状态和 SOC 变化，车辆未开放完整信号时可手工修正。

## 7. 我的音效与车外播放

1. 将 MP3、WAV、AAC、M4A、OGG 或 FLAC 文件放入本地存储根目录 `/storage/emulated/0/WJX`，在文件管理器中就是“所有文件 → 本地 → WJX”。
2. 打开“个性音效 → 我的音效”，点击刷新即可重新载入 WJX 目录中的文件。
3. 点击音效卡片开始车外播放，再次点击当前音效停止。
4. 长按拖动卡片可调整顺序；左滑卡片并在确认弹窗中删除音效。
5. 在“声音调节”中分别设置音效音量、实时喊话音量和喊话降噪强度。
6. 车外没有声音时，进入“设置 → 按键/显示/车外通道”，先选择“自动”，仍不正常再测试 A 或 B 通道。

请在合法、安全且不会干扰他人的场景使用车外播放。

车外音效不会主动暂停、压低或调节车内音乐，音效音量只作用于车外播放器。

## 8. 实时喊话

1. 点击个性音效页的麦克风按钮启动实时喊话，首次使用需允许麦克风权限；再次点击即可停止。
2. 喊话音量、降噪和自动麦克风灵敏度在“声音调节”中单独设置。

实时喊话会占用麦克风和车外音频通道，用完后应及时停止。

## 9. 桌面歌词与仪表盘歌词

1. 打开“桌面组件 → 歌词组件”，桌面歌词和仪表盘歌词需要分别开启。
2. 第三方音乐软件需允许系统通知访问。应用会结合媒体会话、播放通知和歌词来源读取歌曲及进度。
3. 桌面歌词可设置显示在其他应用上层和触摸穿透。开启穿透后，触摸操作会交给下方应用。
4. 在“调节对象”中选择桌面歌词或仪表盘歌词，再设置行数、字号、颜色、当前行高亮、字体、滚动动效和同步微调。
5. 仪表盘歌词还可单独调节水平位置、垂直位置和仪表字号，两套参数互不共用。
6. 切歌后歌词会自动更新，当前行随播放进度滚动。

只显示歌名但歌词不滚动，通常是播放器没有持续上报播放进度。请检查播放通知、通知访问权限和歌词同步微调。

## 10. 桌面卡片悬浮窗

1. 打开“桌面组件 → 桌面卡片”，允许悬浮窗权限后开启卡片。
2. 车辆控制区可加入常用动作，例如左右电滑门、车窗或空调。
3. 车外音效区可从 WJX 音效库加入常用音效，点击播放，再次点击同一音效停止。
4. 悬浮图标可使用内置图片，也可导入自定义静态图或 GIF。GIF 会循环播放。
5. 卡片显示后可拖动到合适位置，应用会保存最后的位置。

过大的 GIF 会增加车机内存占用，建议控制分辨率、帧数和文件体积。

## 11. 智能联动

新安装不会自动创建任何规则，智能联动从空列表开始，请按实际需要新建。

新建规则的步骤：

1. 填写规则名称并添加触发条件。
2. 多条件可选择 AND（全部满足）或 OR（任一满足）。
3. 车辆条件包括车速、档位、SOC、充电枪、电源、温度、车门车窗、空调座椅、轮胎、灯光和智驾状态等。
4. 其他条件包括指定时刻、时间段、周期间隔、服务启动、网络恢复和上车开门。
5. 配置“进入动作”和“退出动作”。进入动作在条件由不满足变为满足时执行，退出动作相反。
6. 可执行动作包括车窗、空调、座椅、电滑门、通知、打开应用、拨号、导航、链接、HTTP、车内/车外音效、音乐/视频、哨兵模式和返回桌面等。
7. 车内播放音效可直接选择 WJX 音效库，保持当前车内媒体音量；循环音效会在规则退出时自动停止。
8. 设置冷却时间可防止信号抖动导致重复触发；重复间隔用于条件持续满足时定时执行，0 表示关闭重复。
9. 保存后在规则列表手动启用。列表支持编辑、复制、删除和查看最近触发记录。

车辆控制类规则请先在停车状态下测试，并先使用低风险动作验证条件是否正确。

## 12. LED 蓝牙屏

1. 打开“设置 → LED 联动”，允许蓝牙扫描和连接权限。
2. 开始扫描并从设备列表选择目标 LED 屏，连接后会显示就绪状态和信号强度。
3. 使用亮度滑块调整屏幕亮度，“恢复微笑画面”可恢复默认待机图案。
4. 内置画面测试可单独发送已知画面，用来检查通信和显示。
5. 在智能联动规则中添加 LED 画面动作，可设置一个或多个画面及各自持续时间，保存后手动开启规则。

连接不稳定时，缩短 LED 屏与车机距离，并确认设备没有连接到其他手机或车机。

## 13. 锁车、解锁与哨兵音效

1. 打开“设置 → 车辆事件音效”，如果 WJX 目录中没有音效，先导入音效。
2. 分别为锁车、解锁和哨兵事件选择音效并打开对应开关。
3. 锁车和解锁会结合门锁与闪灯确认，减少普通数值抖动造成的误播放。
4. 哨兵音效在车机收到原车哨兵报警事件时播放。

只选择文件但没有打开开关不会播放。这三项与智能联动中的插枪、拔枪和倒车音效相互独立。

## 14. 方向盘快捷键与仪表盘投射

### 方向盘快捷键

1. 打开“设置 → 按键/显示/车外通道 → 方向盘快捷键”，点击添加。
2. 选择播放本地音效或实时喊话。
3. 选择单击、双击或长按，点击识别后按下实车方向盘按键，保存并启用。

### 仪表盘投射

1. 开启仪表盘映射后，点击显示按键并学习实车触发键。
2. 独立投射模式需选择目标应用，可调节宽高、水平/垂直位置和缩放。
3. 复制投射模式会把中控当前画面复制到仪表，不需要选择目标应用。
4. 同一个按键同时绑定快捷动作和仪表投射时，快捷动作优先。

仪表可用区域由车型决定，画面超出时需要调整位置和缩放。

## 15. 车辆容量、价格与能耗区间

1. 打开“设置 → 车辆费用与能耗”，填写标称电池可用容量和油箱容量并保存。
2. 填写家用慢充电价、直流快充电价和每升油价。
3. 行程费率可使用慢充价、快充价或自定义电价，新行程按该费率计算。
4. 修改费率后可选择“重新计算全部行程”，历史费用会按新费率更新。
5. 优秀能耗和偏高能耗阈值决定首页本地分析的评价和颜色区间。

## 16. 主题、备份、更新与日志

- 主题：在“设置 → 数据与更新”选择白天、黑暗或跟随系统，背景壁纸会应用到主要页面。
- GPS：开启后只影响新行程的位置点记录，关闭不会删除已有轨迹。
- 导出配置：将用户数据库和可备份设置生成 ZIP，默认保存到本地存储根目录 `/storage/emulated/0/WJX`，文件名为 `ToyBox_backup_日期_时间.zip`；同一秒重复备份时会自动增加序号，避免覆盖已有文件。
- 恢复配置：选择此前导出的 ZIP，确认后覆盖当前用户数据；按界面提示重启或刷新。
- 自动更新：开启后应用启动时按限流规则检查；也可手动点击“检查更新”。
- 安装更新：发现新版本后下载并安装，系统拦截时为超级玩具箱允许安装未知应用。
- ADB 身份：首次允许调试后会在车机系统设置中保存设备绑定的加密密钥备份；同一车机使用同一正式签名重装时会自动恢复，恢复出厂、系统清理或更换签名后需要重新授权。
- 上传日志：点击后直接上传应用生成的当前诊断日志，页面会显示“上传中”“上传完成”或脱敏后的失败原因，不需要开始或停止录制。

用户导出的配置备份不包含服务器授权状态；永久授权由服务器按当前 VIN 自动恢复。ADB 加密身份由系统单独保存，不进入导出 ZIP。应用会从界面错误、当前日志和历史日志中隐藏 URL、部署域名及服务器 IP；日志仍可能包含 VIN、车辆信号和错误堆栈，只应上传到官方后台排查。

## 17. 常见问题

1. 后台功能中断：打开应用确认授权有效，再检查 ADB、自启动、后台运行和电池优化白名单。
2. 悬浮窗不显示：检查悬浮窗权限、功能开关和授权状态，然后关闭再开启一次功能。
3. 歌词不滚动：检查播放器通知、通知访问权限、播放进度是否持续更新，以及歌词同步微调。
4. 仍无法解决：在现象出现后尽快进入“设置 → 数据与更新 → 上传日志”，并向客服提供 VIN、车型、操作时间和具体现象。

应用内的“设置 → 使用说明”支持按分类浏览和关键字搜索，可直接搜索“歌词”“wjx.log”“自启动”等词快速找到对应步骤。
